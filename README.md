# LLM-based Meeting Video Analysis - Prototype  

This repository accompanies the UMAP 2025 paper *Towards Group Decision Support with LLM-based Meeting Video Analysis*.  

## Overview  
The repository contains a Jupyter notebook prototype where all prompts are defined. Follow the instructions in the notebook to run the prototype.  

To simplify the implementation, transcript generation is not included in this notebook. The original prototype, which includes transcript generation, was omitted from publication to maintain author anonymity revealed in its domain.

## Sample Data  
- **Transcript:** A simple example discussion (`sample_discussion.txt`) simulating a trivial group decision on vacation destinations, generated with GPT-4o. While basic, it allows an overview of the meeting analysis process.  
- **Generated Reports:**  
  - Raw JSON report: `sample_discussion_report.json`  
  - Readable Markdown report: `sample_discussion_report.md`  

Due to confidentiality, real meeting transcripts analyzed in the paper are not included.
